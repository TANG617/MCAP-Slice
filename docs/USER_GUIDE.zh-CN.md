# MCAP Slice 用户指南

[项目主页](../README.zh-CN.md)

## 1. 打开录制文件

使用 **Open MCAP…** 打开单个录制，把一个 `.mcap` 文件拖入窗口，或者使用
**Open Folder…** 建立文件夹会话。

文件夹会话只列出该文件夹第一层中的 `.mcap`，不会扫描子文件夹。可以用鼠标或
方向键切换文件；摘要读取和视频索引在后台执行，因此文件列表会保持响应。

单独打开文件会结束当前文件夹会话。打开新文件夹、单独打开文件或重启应用都会
清空话题选择。

## 2. 选择话题

所有话题默认未勾选，只勾选需要写入导出 MCAP 的 topic 名称。

- 当前文件夹会话按照完整 topic 名称记住选择。
- 切换到包含同名 topic 的其他文件时，该 topic 会自动恢复勾选。
- 当前文件缺少的已选 topic 不会从会话中丢失；切回包含它的文件后仍会勾选。
- 同一文件中具有相同 topic 名称的多个 channel 会同步选择并一起导出。
- **Clear selection** 会清空当前文件夹会话的全部选择。
- 只有当前文件加载完成、时间范围有效，并且当前文件中至少存在一个已选 topic
  时，**Export…** 才会启用。

选择表格行会在 **Selected topic schema** 中显示 schema，但不会改变复选框。

## 3. 预览视频

录制中存在兼容视频流时，MCAP Slice 会选择最合适的彩色视频流并索引时间戳。
可以用视频区域顶部的菜单切换预览 channel。

视频预览要求：

- ROS 2 CDR 消息编码；
- schema 为 `sensor_msgs/msg/CompressedImage`；
- 压缩图像格式可以被 Qt 解码。

播放器提供播放/暂停、按帧定位、已播放时间、图像尺寸、像素格式、ROS frame ID
和 capture time。图像帧按需解码。

预览流与导出选择相互独立。预览某个 topic 不会勾选它，清空导出选择也不会关闭
视频预览。

## 4. 设置导出范围

拖动两个范围手柄，或者直接编辑 **In** 和 **Out**。

标准时间格式如下：

```text
2026-07-30T04:06:56.682+08:00
```

时间编辑器：

- 始终使用 `Asia/Shanghai`（`+08:00`）显示；
- 接受带 `Z` 或 `±HH:mm` 的 RFC 3339 时间；
- 接受 1–9 位小数，毫秒之后的部分向下截断；
- 拒绝不带时区的文本；
- 输入无效时保留上一次有效值。

**In** 是包含边界，**Out** 是排除边界，因此 log time 恰好等于 Out 的消息不会
导出。点击 **Reset** 可恢复当前录制的完整范围。

## 5. 导出

选择一种压缩方式：

- **ZSTD**：适合作为通用默认值；
- **LZ4**：更偏向快速压缩和解压；
- **None**：不使用压缩。

点击 **Export…**，选择新的 `.mcap` 路径并等待导出结束。取消导出不会留下不完整
的目标文件。MCAP Slice 拒绝覆盖源文件。

输出只包含 topic 已选中，并且 log time 位于 `[In, Out)` 范围内的消息。

## 6. 可追溯性与 Metadata

MCAP Slice 会保留源 schema、已选 channel、channel Metadata 和全部源顶层
Metadata，然后追加一条 `mcap_slice.provenance.v1`。

记录包含不带目录的直接来源文件名、源文件大小、精确到纳秒的源消息边界、所选
裁剪边界、实际导出话题、工具版本和创建时间。再次裁剪已经裁剪过的文件时，旧
记录会保留，并在末尾追加新记录。

完整字段约定见 [Provenance Metadata](PROVENANCE.md)。

## 常见问题

### Export 按钮不可用

等待文件加载完成，确认 In 早于 Out，并勾选当前文件实际存在的至少一个 topic。

### 时间戳被拒绝

必须包含明确时区，例如 `Z` 或 `+08:00`，并使用 RFC 3339 的 `T` 作为日期与
时间的分隔符。

### 没有视频画面

MCAP 可能没有兼容的 ROS 2 CDR `CompressedImage` channel，或者 Qt 不支持载荷
使用的图像编码。此时话题导出功能仍可使用。

### 因无法保留 Metadata 而停止导出

如果某条顶层 Metadata 无法解析，应用仍允许预览，但会主动阻止导出，避免静默
丢失来源信息。

### 文件没有出现在文件夹列表

列表只显示所选文件夹第一层中的常规 `.mcap` 文件，嵌套文件和其他扩展名会被
忽略。

### 导出文件缺少 attachments

当前导出器不会复制 attachments。请保留原始录制，并在删除源数据之前验证每个
输出文件。

仍无法解决时，请按照[支持说明](../SUPPORT.md)提交问题。
